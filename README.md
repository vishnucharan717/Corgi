# Corgi
Obtained highest Accuracy in the AI hackathon conducted by Corgi AI (San Francisco)
Performed LLM based analysis on Insurance data to predict the Approved amount.
Performed feature Engineering and created a traditional Regressional Model (lower accuracy).
Used the features obtained from the Regressional Model along with extra feature documents per case basis.
Trained GPT by supervised fine tuning - 4omini with Features + document data on multiple runs obtaining an Accuracy of 90%.
Performed QLoRA and RAG based fine tuning as well.
